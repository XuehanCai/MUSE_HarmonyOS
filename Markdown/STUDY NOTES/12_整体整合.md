
# 12_整体整合

## 1. 写页面的顺序

先看整体，再看局部。

顺序：

```text
整体结构 -> 局部结构 -> 内容 -> 美化
```

---
## 2. 这个页面的整体结构

这个页面是一个歌曲列表。

整体可以分成两部分：

```text
页面
├── 标题：猜你喜欢
└── 列表：List
```

代码结构：

```ts
Column() {
  Text('猜你喜欢')

  List() {
    ListItem() {}
    ListItem() {}
    ListItem() {}
  }
}
```

扩充组件安全区域
```
    .expandSafeArea([SafeAreaType.SYSTEM],[SafeAreaEdge.TOP,SafeAreaEdge.BOTTOM])
```

---

## 3. 单个列表项的结构

每一行歌曲是一个 `ListItem`。

一行里面可以分成三部分：

```text
ListItem
└── Row
    ├── 左边：图片
    ├── 中间：歌曲信息
    └── 右边：更多按钮
```

代码结构：

```ts
ListItem() {
  Row() {
    Image($r('app.media.shanghetu'))

    Column() {
      Text('山河图')

      Row() {
        Text('VIP')
        Text('凤凰传奇')
      }
    }

    Image($r('app.media.more'))
  }
}
```

---

## 5. 第一步：先写布局

先不要写颜色、字体、圆角，只写结构。

```ts
Column() {
  Text('猜你喜欢')

  List() {
    ListItem() {
      Row() {
        Image($r('app.media.shanghetu'))

        Column() {
          Text('山河图')

          Row() {
            Text('VIP')
            Text('凤凰传奇')
          }
        }

        Image($r('app.media.more'))
      }
    }
  }
}
```

---

## 6. 第二步：再写内容

把真实文字和图片放进去。

```ts
Text('猜你喜欢')
Text('山河图')
Text('VIP')
Text('凤凰传奇')

Image($r('app.media.shanghetu'))
Image($r('app.media.more'))
```

---

## 7. 第三步：最后美化

布局和内容都对了，再加样式。

```ts
Text('山河图')
  .fontColor('#FEFEFE')
  .fontSize(20)
  .fontWeight(700)

Image($r('app.media.shanghetu'))
  .width(80)
  .border({ radius: 8 })

Row() {
  ...
}
.width('100%')
.height(80)
.backgroundColor(Color.Black)
.margin({ bottom: 15 })
```

---

## 8. 完整结构示例

```ts
Column() {
  Text('猜你喜欢')
    .fontColor('#fff')
    .width('100%')
    .margin({ bottom: 10 })

  List() {
    ListItem() {
      Row() {
        Image($r('app.media.shanghetu'))
          .width(80)
          .border({ radius: 8 })
          .margin({ right: 10 })

        Column() {
          Text('山河图')
            .fontColor('#FEFEFE')
            .fontSize(20)
            .fontWeight(700)
            .margin({ bottom: 20 })

          Row() {
            Text('VIP')
              .fontColor('#9A8E28')
              .border({ width: 1, color: '#9A8E28', radius: 12 })
              .padding({ left: 5, right: 5, top: 5, bottom: 5 })
              .margin({ right: 15 })

            Text('凤凰传奇')
              .fontColor('#696969')
          }
        }
        .layoutWeight(1)

        Image($r('app.media.more'))
          .width(24)
          .fillColor('#FEFEFE')
      }
      .width('100%')
      .height(80)
      .backgroundColor(Color.Black)
      .margin({ bottom: 15 })
    }
  }
}
.width('100%')
.height('100%')
.backgroundColor('#131313')
.padding({ left: 10, right: 10 })
```

---

## 9. 这个例子的记忆点

- 整个页面用 `Column`
- 列表用 `List`
- 每一行用 `ListItem`
- 一行里面左右排列，用 `Row`
- 歌曲文字上下排列，用 `Column`
- `VIP` 和歌手左右排列，用 `Row`
- 先把结构写出来，再加文字和图片
- 最后再加颜色、宽高、边距、圆角
