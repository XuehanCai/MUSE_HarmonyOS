# 06_组件基础语法

## 1. 页面基本结构

```ts
@Entry
@Component
struct Index {
  build() {
    Column() {
      Text('Hello HarmonyOS')
    }
  }
}
```

## 2. 每一部分是什么意思

- `@Entry`：页面入口
- `@Component`：表示这是一个组件
- `struct Index`：定义一个组件，名字叫 `Index`
- `build()`：写页面内容的地方
- `Column()`：纵向布局容器
- `Text()`：文本组件

## 3. Text 文本组件

`Text` 用来显示文字。

```ts
Text('你好')
```

常见写法：

```ts
Text('山河图')
  .fontSize(20)
  .fontColor('#ffffff')
```

## 4. Column 纵向布局

`Column` 里面的内容是从上到下排列。

```ts
Column() {
  Text('第一行')
  Text('第二行')
  Text('第三行')
}
```

记忆：

```text
Column = 上下排列
```

## 5. Row 横向布局

`Row` 里面的内容是从左到右排列。

```ts
Row() {
  Text('VIP')
  Text('凤凰传奇')
}
```

记忆：

```text
Row = 左右排列
```

## 6. Row 和 Column 组合

```ts
Column() {
  Text('猜你喜欢')

  Row() {
    Text('VIP')
    Text('凤凰传奇')
  }
}
```

显示结构大概是：

```text
猜你喜欢
VIP 凤凰传奇
```

## 7. 记忆点

- 页面内容写在 `build()` 里面
- `Text` 用来显示文字
- `Column` 是上下排列
- `Row` 是左右排列
- 容器组件里面可以放子组件
