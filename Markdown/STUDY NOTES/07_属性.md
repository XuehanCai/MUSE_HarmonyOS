# 07_属性

## 1. 属性是什么

属性写在组件后面，用来设置组件的样式。

```ts
Text('你好')
  .width(100)
  .height(50)
  .backgroundColor(Color.Red)
```

## 2. width

`width` 设置宽度。

```ts
Text('你好')
  .width(100)
```

占满父组件宽度：

```ts
Text('你好')
  .width('100%')
```

## 3. height

`height` 设置高度。

```ts
Text('你好')
  .height(50)
```

占满父组件高度：

```ts
Column() {
  Text('你好')
}
.height('100%')
```

## 4. backgroundColor

`backgroundColor` 设置背景颜色。

```ts
Text('你好')
  .backgroundColor(Color.Red)
```

也可以写颜色值：

```ts
Text('你好')
  .backgroundColor('#ff6600')
```

## 5. 组合写法

```ts
Text('你好')
  .width(100)
  .height(50)
  .backgroundColor(Color.Orange)
```

## 6. 记忆点

- 属性写在组件后面
- `width` 是宽度
- `height` 是高度
- `backgroundColor` 是背景颜色
- `100` 是固定大小
- `'100%'` 是占满父组件
