
# 08_文本属性

## 1. fontSize

`fontSize` 设置文字大小。

```ts
Text('你好')
  .fontSize(20)
```

## 2. fontColor

`fontColor` 设置文字颜色。

```ts
Text('你好')
  .fontColor(Color.Red)
```

也可以写颜色值：

```ts
Text('你好')
  .fontColor('#ffffff')
```

## 3. fontWeight

`fontWeight` 设置文字粗细。

```ts
Text('你好')
  .fontWeight(700)
```

## 4. textAlign

`textAlign` 设置文字在组件内部的对齐方式。

```ts
Text('你好')
  .width(100)
  .textAlign(TextAlign.Center)
```

## 5. 组合写法

```ts
Text('山河图')
  .fontSize(20)
  .fontColor('#ffffff')
  .fontWeight(700)
```

## 6. 记忆点

- `fontSize`：文字大小
- `fontColor`：文字颜色
- `fontWeight`：文字粗细
- `textAlign`：文字在自己区域里的对齐方式
