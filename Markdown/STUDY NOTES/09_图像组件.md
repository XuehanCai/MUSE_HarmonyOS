
# 09_图像组件

## 1. Image 是什么

`Image` 用来显示图片。

```ts
Image($r('app.media.shanghetu'))
```

## 2. 本地资源图片

图片放在资源目录`src/main/resources/base/media/background.png`后，可以用 `$r()` 引用。

```ts
Image($r('app.media.shanghetu'))
```

## 3. 设置宽高

```ts
Image($r('app.media.shanghetu'))
  .width(80)
  .height(80)
```

## 5. 图片填充颜色

图标类`AVG`图片可以设置颜色。

```ts
Image($r('app.media.more'))
  .width(24)
  .fillColor('#ffffff')
```

## 6. 记忆点

- `Image` 用来显示图片
- 本地图片用 `$r('app.media.资源名')`
- `width` 设置宽度
- `height` 设置高度
- `fillColor` 常用于图标改颜色

`Text / Image / Button = 单一组件`
`Column / Row / List = 容器组件`
