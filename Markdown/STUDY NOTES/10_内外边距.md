# 10_内外边距

## 1. margin 是什么

`margin` 是外边距。

外边距是组件和外面其他组件之间的距离。（外）

```ts
Text('你好')
  .margin(10)
```
## 2. padding 是什么

`padding` 是内边距。

内边距是组件内容和组件边框之间的距离。（内）

```ts
Text('你好')
  .padding(10)
```

## 3. margin 基本写法

四周都有外边距：

```ts
Text('你好')
  .margin(10)
```

只设置某个方向：

```ts
Text('你好')
  .margin({ left: 10, right: 10, top: 10, bottom: 10 })
```

## 4. padding 基本写法

四周都有内边距：

```ts
Text('你好')
  .padding(10)
```

只设置某个方向：

```ts
Text('你好')
  .padding({ left: 10, right: 10, top: 10, bottom: 10 })
```

## 5. 记忆点

- `margin` 是外边距
- `padding` 是内边距
- `margin` 控制组件和外部的距离
- `padding` 控制内容和边框的距离
- 想让两个组件隔开，用 `margin`
- 想让文字不要贴边，用 `padding`
