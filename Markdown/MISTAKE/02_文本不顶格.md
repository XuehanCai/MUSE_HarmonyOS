
# 02_width 百分比使用错误：边框被拉满

## 问题

`VIP` 的边框被拉成了一整条。而且剧中

## 原因

我把 `.width('100%')` 写到了 `Text('VIP')` 上。

`Text('VIP')` 占满了父组件宽度，所以边框也跟着变长。

## 正确写法

```ts
Row() {
  Text('VIP')
    .fontColor('#9A8E28')
    .border({ width: 1, color: '#9A8E28', radius: 12 })
    .padding({ left: 5, right: 5, top: 5, bottom: 5 })
    .margin({ right: 15 })

  Text('凤凰传奇')
    .fontColor('#696969')
}
.width('100%')
```

## 错误写法

```ts
Row() {
  Text('VIP')
    .fontColor('#9A8E28')
    .width('100%')
    .border({ width: 1, color: '#9A8E28', radius: 12 })

  Text('凤凰传奇')
    .fontColor('#696969')
}
```

## 记忆点

谁需要占满宽度，`.width('100%')` 就写给谁。

`VIP` 只需要根据文字大小显示，所以不能给 `Text('VIP')` 写 `.width('100%')`。
