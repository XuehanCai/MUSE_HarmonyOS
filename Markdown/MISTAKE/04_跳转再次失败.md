
# Builder 使用错误：页面入口和局部组件混用

## 问题

`layout` 页面里的菜单和文本出现一下，然后又消失。

## 原因

我把 `route_map.json` 里使用的页面入口 Builder，改成了底部菜单 Builder。

`route_map.json` 里写的是：

```json
{
  "name": "layout",
  "pageSourceFile": "src/main/ets/pages/layout.ets",
  "buildFunction": "layoutBuilder"
}
```

这表示：

```text
layoutBuilder 是 layout 页面的入口函数
```

所以它应该负责生成整个页面。

## 错误写法

```ts
@Builder
export function layoutBuilder(item: TabClass) {
  Column({ space: 5 }) {
    Image(item.icon)
      .width(24)

    Text(item.text)
      .fontSize(14)
  }
}
```

问题：

```text
这个 layoutBuilder 变成了菜单样式 Builder。
但是路由跳转时不会给它传 item。
```

## 正确写法

页面入口 Builder：

```ts
@Builder
export function layoutBuilder() {
  Layout()
}
```

菜单样式 Builder：

```ts
@Builder
function tabBarBuilder(item: TabClass) {
  Column({ space: 5 }) {
    Image(item.icon)
      .width(24)

    Text(item.text)
      .fontSize(14)
  }
}
```

在 `TabContent` 中使用：

```ts
TabContent() {
  Text('内容')
}
.tabBar(tabBarBuilder(item))
```

## 完整结构

```ts
interface TabClass {
  text: string
  icon: ResourceStr
}

@Builder
export function layoutBuilder() {
  Layout()
}

@Builder
function tabBarBuilder(item: TabClass) {
  Column({ space: 5 }) {
    Image(item.icon)
      .width(24)

    Text(item.text)
      .fontSize(14)
  }
}

@Component
struct Layout {
  tabData: TabClass[] = [
    { text: '推荐', icon: $r('app.media.yinle') },
    { text: '发现', icon: $r('app.media.faxian') },
    { text: '动态', icon: $r('app.media.dongtai') },
    { text: '我的', icon: $r('app.media.wode') }
  ]

  build() {
    NavDestination() {
      Tabs({ barPosition: BarPosition.End }) {
        ForEach(this.tabData, (item: TabClass) => {
          TabContent() {
            Text('内容')
          }
          .tabBar(tabBarBuilder(item))
        })
      }
    }
    .title('布局')
  }
}
```

## 记忆点

- `route_map.json` 里的 `buildFunction` 是页面入口。
- 页面入口 Builder 要返回整个页面组件。
- 局部 UI 样式要单独写 Builder。
- 页面 Builder 和菜单 Builder 不要混用。
