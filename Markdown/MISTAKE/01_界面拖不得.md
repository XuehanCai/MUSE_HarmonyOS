# List 滚动

##问题

页面拖不动。

## 原因

我写了很多个 `List`，每个 `List` 里面只有一个 `ListItem`。
外层 `Column` 不会自动滚动，所以拖不动。

## 正确写法

```ts
List() {
  ListItem() {}
  ListItem() {}
  ListItem() {}
}
.layoutWeight(1)
```

## 错误写法

```ts
Column() {
  List() {
    ListItem() {}
  }

  List() {
    ListItem() {}
  }
}
```

## 记忆点

一个列表只写一个 `List`，多个数据写成多个 `ListItem`。
