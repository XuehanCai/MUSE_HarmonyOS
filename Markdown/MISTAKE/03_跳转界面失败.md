
# 路由名字大小写错误

## 问题

`layout` 页面里的菜单和文本出现一下，然后又消失了。

## 原因

路由名字大小写写不一致。

`route_map.json` 里注册的是小写：

```json
{
  "name": "layout",
  "pageSourceFile": "src/main/ets/pages/layout.ets",
  "buildFunction": "layoutBuilder"
}
```

但是跳转时写成了大写：

```ts
this.pathStack.replacePathByName("Layout", null, false)
```

`"layout"` 和 `"Layout"` 不是同一个名字。

## 错误写法

```ts
this.pathStack.replacePathByName("Layout", null, false)
```

## 正确写法

```ts
this.pathStack.replacePathByName("layout", null, false)
```

## 相关代码

```ts
aboutToAppear(): void {
  setTimeout(() => {
    this.pathStack.replacePathByName("layout", null, false)
  }, 3000)
}
```

## 记忆点

路由名字必须和 `route_map.json` 里的 `name` 完全一样。

大小写也要一样。
